# MINI SPA - TASK MANAGER
A TASK MANAGER BUILT ON THE PRINCIPLES OF SINGLE PAGE APPLICATION.



This application allows users to add new tasks update and delete them by clicking the corresponding button without page reload providing seamless experience.

## TECH STACK USED
HTML,CSS,TS,JS,VITEST.

## Typescript features used

Type aliases \
Union types \
Optional chaining \
Generics 

## FOLDER STRUCTURE

```
/

    ----/components

----/dist

```

## HOW TO RUN
terminal:
```
npm install --global serve
serve -s .
```
open in browser : http://localhost:3000

## HOW TO TEST
terminal:
```
npm run test
```
## HOW TO TYPECHECK
terminal:
```
npx run type-check
```
